# Alternative function for correction of windspeed to reference height rearranged form of the FAO wind-speed height adjustment (https://www.fao.org/3/x0490e/x0490e07.htm)

Alternative function for correction of windspeed to reference height
rearranged form of the FAO wind-speed height adjustment
(https://www.fao.org/3/x0490e/x0490e07.htm)

## Usage

``` r
windheight(ui, zi, zo)
```

## Arguments

- ui:

  original windspeed \[m/s\]\]

- zi:

  measurement height \[m\]

- zo:

  reference height \[m\]

## Value

uo corrected windspeed \[m/s\]
